# 수치 검수표 (PRD F-11)

「식탁 문제 해결단」 학생 화면(`activities/meal-intro.html`, `activities/meal-lab.html`)과 교사용 안내(`activities/meal-lab-teacher.html`)에 나오는 숫자의 출처와 확인 상태를 적은 표입니다. 마지막으로 확인한 날은 2026-11-20입니다.

**상태 표기**

- **원문 확인**: 법령, 공문서, 공표 통계표의 원문에서 숫자를 직접 읽었습니다.
- **2차 자료로 확인**: 원문을 인용한 기관 게재본이나 보도에서 같은 값을 읽었습니다. 원문 대조는 아직 하지 않았습니다.
- **직접 계산**: 이 저장소의 스크립트로 원자료에서 계산했습니다. 다시 실행하면 같은 값이 나옵니다(무작위 씨앗 20261117).
- **가상 값**: 수업을 위해 만든 값입니다. 실제 제품이나 실제 기준이 아닙니다.

기준이 개정되면 이 표, 앱의 상수, 교사용 안내 12절을 함께 고쳐야 합니다. 앱의 상수가 있는 곳은 아래 각 표의 "쓰인 곳" 열에 적었습니다.

**넣지 않은 것**

- 학교급식법 시행규칙의 학교급식 영양관리기준(학교급별 한 끼 열량 등): 원문을 확인하지 못했습니다. 앱은 이 값 대신 학생이 직접 기준선을 넣고 출처를 적게 합니다.
- "1일 영양성분 기준치는 2,000 kcal 기준"이라는 문구: 위 안내서에서 찾지 못했습니다. 그래서 앱에 쓰지 않았습니다.

**찾지 못한 것**

- 2014~2015년 값.
- 학년별 값. PRD F-05는 학년별 값까지 요구하므로 이 부분은 덜 채워졌습니다.
- 과일, 채소, 우유, 단맛 음료 지표의 여러 해 값.
- 전체(남녀 합계) 값. 주요통계 표에는 없었습니다. 남녀 값을 평균하지 않았습니다. 성별 표본 크기가 달라 단순 평균은 전체 값이 아닙니다.
