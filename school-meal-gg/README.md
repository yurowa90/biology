# 경기도 고등학교 급식 데이터 (식탁 문제 해결단)

「식탁 문제 해결단」 PBL 웹 데이터 탐구 도구의 데이터 준비 단계 산출물입니다.
경기도 고등학교 전체의 점심 식단을 나이스 교육정보 개방 포털에서 모아, 수업용 집계표로 줄였습니다.

- **범위:** 경기도 고등학교(운영 중인 본교) 504곳. 점심 기록이 있는 곳은 503곳입니다. 수원 중앙기독고등학교는 기록이 조회되지 않습니다.
- **기간:** 2024년 3월 4일 ~ 2026년 11월 13일 (2024·2025학년도 전체, 2026학년도 11월 13일까지)
- **규모:** 점심 244,944끼, 요리 항목 1,534,769건
- **수집일:** 2026년 11월 16~17일

원본(학교별 JSON 504개, 347MB)은 저장소에 넣지 않았습니다. 아래 순서로 다시 받을 수 있습니다.

python3 match_schools.py 8     # 1. 경기도 고등학교 → 나이스 학교 코드 대조 → data/schools_neis.json
python3 collect504.py 8        # 2. 학교마다 141주를 주 단위로 조회 → data/meals/<코드>.json (약 2시간 20분)
python3 analyze_gg.py          # 3. 특이값 처리(outliers_gg.py) 후 집계 → out/*.csv, 처리 기록, 화면 요약
python3 analyze_gg.py --raw    #    (비교용) 처리 전 원본 그대로 집계 → out_raw/*.csv
python3 checks_gg.py           # 4. 검증: 빠진 학교, 이상값의 쏠림, 시군 대 학교 분산
python3 checks2_gg.py          #    2024년 3~4월 영양소 급변, 같은 달끼리 비교한 유행 추세, 무작위 섞기 검정
python3 checks3_gg.py          #    표기 다양성, 바다에 접한 시군의 생선 비율

## 특이값 처리

### 원칙

데이터 과학과 연구 방법 문헌의 공통 권고를 따랐습니다.

- **오류만 지웁니다.** 특이값은 오류, 흥미로운 값(실제로 드문 값), 영향력 있는 값으로 나뉩니다. 오류가 아닌 극단값을 지우면 결론이 바뀌고, 그 자체가 왜곡입니다(Aguinis, Gottfredson & Joo, 2013).
- **선별 → 진단 → 편집 순서를 밟습니다.** 처리 기준, 건수, 처리 전후 결과를 함께 보고합니다(Van den Broeck 외, 2005).
- **평균±표준편차가 아니라 중앙값±MAD로 찾습니다.** 평균과 표준편차는 특이값 자체에 끌려가서 기준이 흔들립니다(Leys 외, 2013). 영양소는 오른쪽으로 꼬리가 긴 분포라 로그 척도에서 계산했습니다.
- **기준은 보수적으로 둡니다.** z=5로 잡았습니다. 로그 정규분포라면 24만 끼 중 우연히 이 거리를 넘는 끼니가 1끼도 안 되는 거리입니다. Leys 외(2013)의 기본값 2.5는 연구 표본용이라, 실제 드문 급식까지 지울 수 있어 쓰지 않았습니다.
- **기록 단위를 구분합니다.** 끼니 기록을 지우는 것은 급식이 아닌 기록뿐입니다. 영양 값이 틀린 끼니도 메뉴(요리 이름)는 남기고, 틀린 값만 결측으로 바꿉니다.

### 진단에서 확인한 것

- **기록 열량은 3대 영양소로 계산됩니다.** 기록 열량과 3대 영양소로 다시 계산한 열량(탄수화물·단백질 4kcal/g, 지방 9kcal/g)의 비는 끼니의 98%에서 0.98~1.04입니다. 시스템이 열량을 3대 영양소로 계산한다는 뜻입니다.
- **극단적인 열량은 재료량 입력 오류입니다.** 575,247kcal 끼니에는 단백질도 28,047g이 함께 기록되어 있습니다. 열량만 틀린 것이 아니라 재료량 자체가 잘못 들어가 영양 기록 전체가 틀렸고, 열량만 고쳐 쓸 수 없습니다.
- **미량 영양소는 열량이 정상이어도 따로 틀립니다.** 티아민 37mg, 철분 186mg, 장어덮밥의 비타민A 67,713R.E처럼 음식으로는 나올 수 없는 값이 있습니다.

### 남긴 극단값과 판단이 필요한 것

- **보수적 기준이라 남긴 큰 값이 있습니다.** 비타민C 584mg, 칼슘 1,494mg, 철분 20.6mg, 열량 1,500~2,009kcal 같은 값입니다. 칼슘강화밥처럼 강화 식품이 있어 오류라고 단정할 수 없어서 남겼습니다. 영양교사의 판단을 받아 기준을 조정할 수 있습니다.
- **2024년 3~4월 칼슘은 모든 학교에서 지웠습니다.** 정상으로 보이는 107곳의 값까지 포함됩니다. 어느 학교가 정상인지 가려낼 근거가 약해서입니다.
- **원본은 그대로 보존합니다.** 처리는 `out/` 집계에만 적용됩니다. `checks*_gg.py`와 `diag*_outliers.py`는 원본으로 진단하고, 정제 미션도 원본 표본을 씁니다.

## 알려진 한계와 오류

분석 전에 반드시 읽어야 할 사항입니다. 2·3번은 위의 특이값 처리로 집계에서는 걸러졌지만, 정제 미션의 소재로 원본에는 그대로 남아 있습니다.

1. **재료는 요리 이름에서 추정한 값입니다.** 나이스 식단에는 재료 목록이 없습니다. 낱말 사전을 바꾸면 값이 달라집니다.
   - "쑥"이 쑥갓을 잡습니다.
   - 음식 궁합의 닭–삼계 배율에는 "닭다리삼계탕"처럼 한 요리 이름에 둘이 함께 든 경우가 섞여 있습니다.
2. **칼슘 값이 2024년 3~4월에만 평소의 4배가 넘습니다.**
   - 한 끼 중앙값이 1,136mg(3월)과 1,033mg(4월)이고, 5월부터는 218~256mg입니다.
   - 열량과 나머지 영양소는 변하지 않았습니다. 기록 방식이 바뀐 것으로 보이지만 원인은 확인하지 못했습니다.
   - 칼슘을 비교하려면 이 두 달을 빼야 합니다.
3. **열량 입력 오류가 있습니다.** 최대 575,247kcal인 끼니가 있습니다. 5,000kcal 초과는 20끼, 300kcal 미만은 456끼입니다.
4. **기간이 고르지 않습니다.**
   - 3개 학년도 기록이 모두 있는 학교는 471곳입니다.
   - 1·2월은 방학이라 끼니가 적습니다.
   - 학년도끼리는 같은 달끼리만 비교해야 합니다.
5. **경기도 전수입니다.** 경기도에 대해서는 표본 오차가 없지만, 전국으로 일반화할 수 없습니다.
6. **없는 변수가 있습니다.** 나트륨, 당류, 재료 목록, 잔반량은 없습니다.
