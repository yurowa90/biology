# 통합과학 · AI 디지털교과서

고등학교 통합과학1·2(2022 개정)를 위한 탐구형 디지털교과서입니다.

사이트 주소: <https://yurowa90.github.io/biology/>

## 누구를 위한 자료인가

- **학생**: 개념을 읽기만 하지 않고 예측 → 유도 → 시뮬레이션 → 평가 → 성찰을 스스로 밟아 가는 활동을 합니다.
- **교사**: 학생이 제출한 보고서를 반별로 모아 문항별 정답률과 서술형 답안을 확인합니다.

## 쓰기 전에 알아 둘 점

- 로그인이나 API 키가 필요 없습니다. 서술형·수행과제 피드백(자가 점검·예시 답안·자기평가)은 학생 브라우저 안에서 만들어지며 어떤 AI 서비스도 호출하지 않습니다.
- 답안과 진행 상황은 학생 브라우저(localStorage)에 저장됩니다.
- 쓰는 자료(NOAA ONI, Open-Meteo 해수면 온도)는 키가 필요 없는 공개 자료입니다. 실시간 해수면 온도는 학생이 버튼을 누를 때만 브라우저에서 불러옵니다.

| 엘니뇨·라니냐 워크북(`activities/enso.html`) | 통합과학2 Ⅴ-2, 성취기준 [10통과2-02-03]. 시뮬레이터와 실제 관측 자료를 쓰는 8단계 탐구 |
| 교사 대시보드(`teacher.html`) | 학생 제출을 반별로 누적·집계(현재 효소 워크북 전용) |

목차 뼈대는 비상교육 「통합과학1·2」(2022 개정)를 기준으로 합니다. 성취기준은 확인된 코드만 표기하고, 확인하지 못한 소단원은 홈에 "성취기준 확인 필요 · 비상 교과서 대조 예정"으로 표시합니다. 활동·예시·탐구 소재는 동아·미래엔·지학사·천재교육 교과서를 교차 참고할 예정입니다.

활동 유형은 6종입니다: `개념` · `시뮬레이션` · `PBL` · `GRASPS`(수행과제) · `형성평가` · `성찰`.

아직 만들지 않은 소단원·활동은 홈 목차에 "준비 중"으로 올라가 있습니다. 다음 후보는 자연선택 시뮬레이터(Ⅳ-2), 생태계 평형·교란 시뮬레이션(Ⅴ-1), 산화·환원 탐구(Ⅳ-3), 여러 활동을 함께 보는 교사 대시보드입니다.

| # | 단계 | 내용 |
|---|------|------|
| 01 | 예측·진단 | 채점하지 않는 예측 3문항 + KWL의 K·W |
| 02 | 개념 | 무역풍·용승·수온약층·워커 순환, 엘니뇨·라니냐, ONI 판정 기준, 지구온난화와의 관계 |
| 03 | 시뮬레이터 | 무역풍 세기 슬라이더로 적도 태평양 단면 애니메이션(따뜻한 해수·수온약층 기울기·용승·워커 순환·강수 중심), 라니냐/평상시/엘니뇨 프리셋, 실시간 수치 8종, 자동 체크리스트, 지역별 원격 영향 카드 |
| 04 | 실제 데이터 | NOAA ONI 시계열 차트(±0.5 기준선, 공식 엘니뇨·라니냐 구간 음영), 현재 상태 자동 판정, 강한 사례(1997–98·2015–16·2023–24) 최고점 찾기, 실시간 해수면 온도로 "지금 바다는 시뮬레이터의 어느 상태?" |
| 05 | 형성평가 | 4문항 즉시 채점·해설 |
| 06 | GRASPS | 청중이 다른 과제 3개(교실 / 학교 공동체 / 전문가·국제 사회) 중 하나를 골라 산출물 작성 → 키워드 자가 점검 + 평가 기준별 자기평가(충족/부분/보완) + 예시 개요 |
| 07 | 성찰 | KWL(1단계의 K·W를 이어받아 L 작성), 자기평가 3항목, 세계 시민 성찰 |
| 08 | 보고서 | 효소 워크북과 같은 방식으로 제출 |

시뮬레이터는 원리를 보여 주는 개념 모델이며(화면에 명시), 수치는 경향을 나타낼 뿐 관측값이 아닙니다. 화면에는 ONI 자료의 출처·범위·수집 시각을 늘 표시합니다. 자료를 불러오지 못하면 "데이터 없음"을 표시하고, NOAA `oni.ascii.txt` 파일을 직접 불러오도록 안내합니다.

## 효소반응속도 워크북

| # | 단계 | 내용 |
|---|------|------|
| 01 | 예측 | 채점하지 않는 직관 문항 — [S]를 높이면 v는? 효소 2배면 Vmax는? |
| 02 | 이론 유도 | E+S⇌ES→E+P에서 정상상태 가정으로 `v = Vmax·[S]/(Km+[S])` 유도(6단계 아코디언) |
| 03 | 회전수 kcat | `Vmax = kcat·[E]₀`, 촉매효율 kcat/Km, 낮은/높은 기질 농도에서의 거동 |
| 04 | 시뮬레이터 | 효소 반응 애니메이션 + v–[S] 포화 곡선 ↔ 이중역수(Lineweaver–Burk) 그래프. Vmax·Km·[S]·억제제(경쟁적/비경쟁적) 슬라이더, 실시간 수치와 체크리스트 |
| 05 | 유도 확인 | 유도 단계를 확인하는 4지선다 4문항, 즉시 채점·해설 |
| 06 | 형성평가 | 포화·효소 농도·억제제·회전수 종합 4문항 |
| 07 | 서술형 · 자가 점검 | 서술형 2문항 + 키워드 자가 점검 + 예시 답안 |
| 08 | 최종 보고서 | 전체 답안·점수 정리 → 제출 / 인쇄(PDF) / 다운로드 |

## 서술형·수행과제 피드백

외부 AI 호출이나 API 키 없이 브라우저 안에서 동작합니다.

- **자가 점검**: 답안에서 점검 항목에 해당하는 표현을 찾아 ✓(발견) / △(보완)과 안내 질문을 보여 줍니다. 안내 질문은 정답 문장을 주지 않습니다. 화면과 보고서에 "키워드 기반 자동 점검 — 참고용이며 최종 평가는 선생님이 합니다"를 표시합니다.
- **자기평가(엘니뇨 GRASPS)**: 평가 기준마다 학생이 충족/부분/보완을 고르며, 보고서에는 "학생 자기평가 + 자동 점검(키워드 기반) · 교사 확인 필요"로 기록됩니다.
- **예시 답안·예시 개요**: 학생이 직접 60자 이상 쓴 뒤에 열 수 있고, 열람 여부와 시각이 보고서에 남습니다. 교사 대시보드에는 "예시답안 열람"으로 표시됩니다.
- **AI 도우미용 프롬프트 복사(선택)**: "정답을 주지 말고 힌트로 피드백해 달라"는 프롬프트를 만들어 클립보드에 복사만 합니다(네트워크 사용 없음). 학교에서 허용한 AI 도구에 붙여 넣어 쓰며, 이 버튼은 끌 수 있습니다.
- 예전 버전이 학생 브라우저에 저장했던 API 키는 활동 페이지를 열 때 자동으로 지웁니다.

## 보고서 제출

인쇄(PDF 저장)와 JSON 다운로드는 항상 쓸 수 있습니다. 제출 방식은 활동 파일 상단의 설정(`CONFIG.submit.mode`)으로 고릅니다.

| 방식 | 동작 | 필요한 설정 |
|------|------|------|
| `download`(기본) | 보고서를 JSON 파일로 저장 → 학생이 구글 클래스룸이나 이메일로 제출 | 없음 |
| `googleForm` | 구글 폼으로 보내 연결된 스프레드시트에 자동 기록 | 폼 ID와 항목 번호 |
| `endpoint` | Formspree 같은 임의의 POST 주소로 전송 | 주소 1개 |

**구글 폼으로 모으기**
1. 구글 폼을 만들고 필요한 항목마다 단답형 질문을 추가합니다(모두 "필수 아님"). 전체 답안을 통째로 저장하려면 `payload` 항목 하나만 있어도 됩니다.
2. 폼 미리보기에서 페이지 소스를 열어 각 질문의 `entry.XXXXXXX` 번호를 찾습니다.
3. `CONFIG.submit.mode`를 `"googleForm"`으로 바꾸고 `googleForm.formId`와 `entries`를 채웁니다. `formId`는 폼 주소 `.../forms/d/e/<formId>/viewform`의 가운데 부분입니다.
4. 폼 응답을 스프레드시트에 연결하면 학생이 제출할 때마다 한 줄씩 쌓입니다.

## 교사 대시보드

사이트의 `teacher.html`(<https://yurowa90.github.io/biology/teacher.html>)에서 엽니다. 서버 없이 동작합니다.

자료를 넣는 방법:
1. **파일 가져오기**: 학생이 내려받아 제출한 보고서 JSON을 끌어다 놓습니다. 자료는 이 브라우저(localStorage)에만 저장되고 밖으로 보내지 않습니다.
2. **구글 시트 CSV**: `googleForm` 방식을 쓸 때 응답 시트를 "파일 → 공유 → 웹에 게시 → 쉼표로 구분된 값(.csv)"으로 게시한 주소를 넣습니다. `payload` 열이 있으면 문항별 분석까지, 없으면 이름·점수·서술형만 집계합니다. 게시 링크는 누구나 볼 수 있으므로 학생 개인정보에 유의하세요.

볼 수 있는 것:
- **개요**: 제출 인원, 유도 확인·형성평가 반 평균, 서술형 작성률, 정답률이 가장 낮은 문항 3개
- **학생 명단**: 정렬되는 표. 행을 누르면 그 학생의 예측·정오답·서술형 전문
- **문항 분석**: 문항별 정답률과 선택지 분포, 예측(사전 개념) 분포
- **서술형**: 학생별 답안, 키워드 점검 점수, 예시답안 열람 여부·시각
- **CSV 내보내기 / 모두 지우기**

## 직접 배포하거나 로컬에서 열기

- 로컬에서 확인만 하려면 `index.html`을 브라우저로 열면 됩니다. 이때는 `data/oni.json`을 읽지 않고 페이지에 내장된 ONI 스냅샷을 쓰며, 스냅샷이 없으면 파일 불러오기를 안내합니다.
- 자기 GitHub 저장소에 올려 쓰려면 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하고 푸시합니다. 배포가 끝나면 `https://<사용자명>.github.io/<저장소명>/`에서 열립니다. Source를 "Deploy from a branch"로 두면 실제 ONI 자료 대신 자리표시 파일이 게시되어 "데이터 없음"이 뜰 수 있습니다(활동은 정상 동작하며 파일 불러오기로 대신할 수 있음).

## 알려진 한계

- 시뮬레이터는 개념 모델이며 관측값을 재현하지 않습니다.
- 자가 점검은 키워드 기반이라 참고용입니다. 최종 평가는 교사가 합니다.
- 교사 대시보드는 현재 효소 워크북 보고서만 집계하고 다른 활동 기록은 건너뜁니다.
- 저장소에 들어 있는 `data/oni.json`은 자리표시입니다. 배포된 사이트에는 배포할 때 받은 실제 값이 들어갑니다.
